# Tests

## Test 1 - Page and playground load [sanity]
Viewport: desktop (1280x800)
Steps:
1. Navigate to the app
2. Confirm the heading "Signals and stores for TypeScript" is visible
3. Scroll to "Watch one effect react."
Expected: The effect log shows run #1 with "Ada Lovelace · 0" and "effect runs" shows 1.

## Test 2 - Batch runs the effect once
Steps:
1. Click "3 writes"
2. Click "3 writes in batch()"
Expected: The first click reports "→ 3 runs", the second "→ 1 run".

## Test 3 - Dynamic dependency
Steps:
1. Uncheck "effect reads count"
2. Click "count++"
Expected: The count edge turns dashed and the action reports "→ 0 runs".
